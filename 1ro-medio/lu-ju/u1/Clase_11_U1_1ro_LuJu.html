🧠 Actividad 2 — Language Focus

Used to describe habitos o situaciones del pasado que ya no ocurren. Es muy util para comparar tecnologias antiguas y actuales.

Used to + infinitive
Examples
  • Affirmative: Mechanics used to fix cars without computers.
  • Negative: They didn't use to have digital multimeters.
  • Interrogative: Did they use to weld by hand?
  • Contrast: Mechanics used to use only hand tools. Now they use diagnostic software.
Sentence frames & tips
  • Subject + used to + base form (NEVER used to + ing).
  • Subject + didn't use to + base form (without final -d in use).
  • Always implies: this is NOT true today.

📖 Actividad 4 — Reading Text — Then and Now: How Technology Changed the Workshop

Automotive: Mechanics used to diagnose problems only by ear and by feel. They didn't use to have computer scanners. Now, a modern mechanic connects an OBD-II scanner and reads the engine error codes in seconds.

Industrial: Welders used to use only oxy-acetylene torches. They didn't use to have automatic welding robots. Now, many factories use MIG and TIG welding, and some lines use programmable robotic arms.

Electricity: Electricians used to measure voltage with analog meters and a screwdriver test. They didn't use to have digital multimeters. Now, a modern multimeter shows voltage, current and resistance on a clear digital display.

Electronics: Engineers used to draw circuits by hand and solder large components on big boards. They didn't use to have CAD software. Now, circuits are designed in software and PCBs are printed with micro-components.

Graphic Arts: Printers used to set type letter by letter and use only black ink. They didn't use to have digital files. Now, all design is done on computers and printing uses CMYK with extreme precision.

📝 Actividad 5 — Reading comprehension

Responde regresando al texto. Busca evidencia concreta antes de revisar la respuesta sugerida.

1. How did mechanics used to diagnose problems before scanners?

Only by ear and by feel.

2. What modern equipment replaced analog meters in electricity?

Digital multimeters.

3. What did engineers use before CAD software?

They drew circuits by hand and soldered large components on big boards.

4. How did printers used to work before digital files?

They set type letter by letter and used only black ink.

5. What pattern does the text follow in every paragraph?

First it describes the OLD practice with used to, then the NEW practice in present simple.

6. Infer: which of the 5 changes do you think had the BIGGEST impact and why?

Open answer: e.g., CAD software, because it transformed not only the speed but the level of complexity that engineers can design today.

🚀 Actividad 6 — Apply & Extend: produce tu COMPARISON POSTER

Vas a crear un poster real comparando una practica tecnica de hace 40 anos vs hoy. Tu poster ensena de un vistazo.
  1. Elige una especialidad y un proceso especifico (no toda la especialidad).
  2. Disena 2 columnas: THEN (used to) y NOW (present). Llena 4 filas con detalles concretos.
  3. Cada fila de THEN debe tener una oracion con used to o didn't use to; cada fila de NOW debe ir en present simple.
  4. Cierra con UNA oracion explicando la consecuencia humana de la tecnologia: mas seguridad, mas precision, menos trabajo manual.
✅ Auto-chequeo antes de entregar
  • Mi proceso es ESPECIFICO (no everything in mechanics).
  • Las 4 oraciones con used to son gramaticalmente correctas.
  • Mi consecuencia humana esta justificada con un detalle.
  • Un companero entiende el poster en 30 segundos.
