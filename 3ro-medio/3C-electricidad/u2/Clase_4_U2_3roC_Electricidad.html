📖 Reading: Wires and cables

A cable is a set of insulated wires. Each wire has a copper core covered by plastic insulation.

The thickness is described by the AWG gauge: a smaller AWG number means a thicker wire and more current capacity. For example, AWG 14 is common for lighting and AWG 12 for outlets.

In Chile, the color code is: phase (live) is red or black, neutral is blue, ground is green or yellow/green. To connect a wire, the electrician strips the insulation with a stripping tool.
