📖 Reading: A practice board with one hidden problem

Students assemble a small practice board with a battery, a switch, a fuse and a lamp. The diagram is correct, but the lamp still stays off.

The teacher asks them to think component by component. The battery was checked yesterday, the switch clicks correctly, and the fuse looks intact. When they inspect the socket, they find one loose connection.

The class learns that knowing the function of each component helps reduce random trial and error during troubleshooting.

📝 Read and answer

Responde usando evidencia del texto y una idea propia cuando se te pida.

1. Which components are included on the practice board?

A battery, a switch, a fuse and a lamp.

2. What problem do students find after checking the function of each part?

One loose connection in the socket.

3. Why does component knowledge reduce trial and error?

Because students can check each function logically instead of guessing.
